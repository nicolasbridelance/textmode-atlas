# Retirer, revendiquer, corriger, témoigner

*[Read in English](TAKEDOWN.md) — la version anglaise fait référence.*

Chaque fiche du musée propose quatre actions. Chacune ouvre un ticket de modération.

| Action | Effet |
| --- | --- |
| **Retirer** | l'œuvre est masquée immédiatement, sans justification demandée ; le fichier quitte le stockage public et le cache est purgé |
| **Revendiquer** | après vérification, l'œuvre est rattachée à votre pseudonyme ; vous pouvez autoriser son affichage, et seulement si vous le souhaitez, lier ce pseudonyme à votre nom |
| **Corriger** | une attribution, une date ou un groupe faux est corrigé par une nouvelle assertion ; l'ancienne reste dans l'historique, marquée remplacée |
| **Témoigner** | votre récit est conservé comme témoignage, avec votre accord écrit |

## Comment faire, aujourd'hui

Le site n'a pas encore de formulaire. En attendant :

- **pour un retrait**, écrivez à **ennead.studio@gmail.com** (objet : « textmode-atlas retrait »)
  plutôt que d'ouvrir un ticket public. Un lien vers la fiche, ou le titre et le pseudonyme,
  suffisent ;
- pour le reste, ouvrez un ticket avec le modèle correspondant.

Un retrait n'exige aucune preuve de propriété : dans le doute, le musée retire. Une demande
d'affichage, elle, est vérifiée avant d'être appliquée.
