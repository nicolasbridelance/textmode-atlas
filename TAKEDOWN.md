# Withdraw, claim, correct, testify

*[Lire en français](TAKEDOWN.fr.md)*

Every record in the museum offers four actions. Each one opens a moderation ticket.

| Action | Effect |
| --- | --- |
| **Withdraw** | the work is hidden immediately, with no justification asked; the file leaves public storage and the cache is purged |
| **Claim** | after verification, the work is linked to your handle; you may allow it to be shown, and only if you wish, link that handle to your name |
| **Correct** | a wrong attribution, date or group is corrected by a new assertion; the old one stays in the history, marked as superseded |
| **Testify** | your account is kept as a testimony, with your written consent |

## How to do it today

The site has no form yet. Until it does:

- **for a withdrawal**, write to the project's contact address (*to be published with the domain
  name*) rather than opening a public issue;
- for anything else, open an issue with the matching template.

A withdrawal requires no proof of ownership: when in doubt, the museum withdraws. A request to
show a work is verified before it is applied.
