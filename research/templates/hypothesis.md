# NNNN. <hypothesis in one sentence>

Copy to `research/NNNN-short-name/hypothesis.md` and commit it **alone, before any look at the
test packs**: the commit date is the proof of pre-registration (research program, rule 2).

- Lead: <H…, Q… in docs/leads.md>, and what the exploration showed (link, train packs only)
- Date: YYYY-MM-DD

## Question

What is asked, of which works, in which years.

## Data

Dataset, version, tables; the split read (test packs for a confirmatory test); exclusions,
decided now.

## Measure

The statistic, defined so that someone else computes the same number.

## Null model

What the statistic would be if the hypothesis were false (permutation within years, random
packs, a shuffled label…), and how it is drawn.

## Test that could fail

The decision rule, set now: threshold, interval, number of resamples (by pack), and what result
would refute the hypothesis.

## Coverage and limits

What the corpus lacks for this question (lost items, sources' gaps), and what a positive result
would still not show.
