# Exhibitions

Tours of 12 to 20 works, 5 to 8 minutes, written by a named person, with a beginning and an end.
Licensed CC BY 4.0. One directory per tour, one file per language (`en.md`, `fr.md`, …); a
translation names its translator, and a machine translation is marked as one.
