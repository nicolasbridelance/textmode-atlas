# 2026-10-10 — the museum on main, chance, a tidy root

## Goal

Publish the unified museum, then follow the owner's new requests: encourage discovery
of the corpus by chance in many places, find the famous works, use the downloaded
Wikipedia pages, a live EDA read from the database, and tidy the repository root.

## Done

- [#109](https://github.com/nicolasbridelance/textmode-atlas/pull/109): the unified
  museum (ADR 0027) and the Windows restoration merged on `main`, CI green.
- [#110](https://github.com/nicolasbridelance/textmode-atlas/pull/110): chance in the
  collection. A `seed` reshuffles the collection reproducibly (shareable URL); "A work
  at random" draws one work within the current filters, server-side among decoded works
  whose files may be shown. Fixed on the way: `/en/…` pages could not navigate at all
  (English is built unprefixed); the host now redirects them.
- Leads Q38 (famous works and their witnesses) and I69–I73 (chance, slideshows, walks on
  the constellation, Wikipedia beside the works, live EDA).
- Root tidied: about sixty `.local-*` files and folders, zips and other agents' notes are
  in the ignored `.local/`; worktrees moved with `git worktree move`. Nothing deleted.

## Decisions

- Chance is seeded, never `Math.random` alone: a draw is reproducible and can be shared,
  and the default seed keeps first visits identical.
- The draw happens on the host, so rights stay server-side (invariant 6).

## Problems

- `localhost` stalls PostgreSQL on this machine; `.env` now uses 127.0.0.1.
- Native `just check` cannot pass on Windows (no `arj`): pushes run the hook in the Linux
  validation container. Editing a file during the hook fails it; message changes need
  Paraglide recompiled in the container.
- `.local-migration/` could not be moved (a process holds it); it stays at the root.

work) is a lead to verify, not yet a finding.
