# 2026-10-09 — Corpus lexicon, independent Codex worktree

## Goal

The owner asked Codex to work independently of Claude, then to make the work durable in the
repository instead of `/tmp`. A lexical first reading, concordance and raw credit registries
support I51/I53 without changing Claude's explorer implementation.

## Done

- `research/lexicon/`: portable builder, whole-token concordance, standalone report template
  and method note. `just lexicon` and `just concordance TERM` are the entry points.
- SHA-256-verified snapshot of works/text; outputs and scratch files go to ignored
  `datasets/build/lexicon/1/`. One DuckDB thread, no production database or shared service.
- NFC/casefold tokens; occurrence and per-file counts separated; explicit era denominators,
  unresolved raw SAUCE registries, contexts with file hash and stored grid row.
- Analysis recipe records version, computational origin and source-code hashes. Generated
  reports and excerpts are private; nothing changes public export or audience rules.
- Tests on synthetic text cover repeated words, Unicode, boundaries, textless files, raw
  credits, source integrity, script embedding, deterministic rebuild and concordance filters.

## Decisions

Source and tests are versioned; generated corpus material is not. The HTML is a local research
report, not a museum page. A separate worktree on `feat/corpus-lexicon` keeps Claude's branch,
index and files untouched. Any integration into the explorer is a later coordinated change.

## Problems met

An ordered text aggregation exceeded a bounded DuckDB memory budget in the temporary lab.
Read source lines in batches and aggregate one file at a time instead. Data paths no longer
depend on `/tmp` or a particular checkout.

## Field notes

No new historical claim. The existing BBS-vocabulary lead is recomputed with explicit Unicode
token boundaries; this remains exploratory, not a validated classification of advertisements.

## State at the end

On works v5: 88,642 files, 76,843 with text, 909,553 lines, 3,936,401 retained tokens and 227,852
forms. Credits normalize to 8,054 author strings and 3,797 group strings, not resolved people
or groups. The report exposes 2,902 unsupported-format files in the train dataset.

Validation: lint, formatting, types, licenses, corpus schema, artwork exclusion and duplication
checks; synthetic-data tests and the Python suite excluding service tests; desktop/mobile
rendering checks with no automatic network requests. Tests that touch PostgreSQL/S3 are deferred to CI to
avoid interfering with shared services; this change itself reads only Parquet files.
