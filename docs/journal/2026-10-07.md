# 2026-10-07 — Session 1: framing and scaffold

## Goal

Take over the project, revise the foundation document, and scaffold the repository on the
target architecture before building the work screen.

## Done

- Foundation document revised: scene radio and work music, three-path display strategy
  (permission, deposit, metadata-only), ninth invariant (no generated works), grid model limits
  (proportional AA fonts), accessibility, mobile display, research outcomes, risks, datasets,
  languages, scaffold deviations.
- Scaffold (branch `scaffold`): uv workspace, SQL schema with invariant triggers and tests,
  write-once storage on Garage, `can_display()` at 100% branches, corpus models with localized
  titles, VGA font, SvelteKit 3 site in English and French, CI, REUSE, hooks.
- Working organization: code rules mechanized (ruff, ESLint, vulture, deptry, knip, jscpd),
  commit message rules with a hook, roadmap, this journal, working protocol in CLAUDE.md,
  `just shots` for screenshots.

## Decisions

- Build at the target architecture from the first line, even for a proof of concept (Nicolas).
- Repository in English; museum multilingual (en and fr required). Foundation document and
  research reports stay in French.
- Garage replaces MinIO, which is no longer published as an image.
- The ansilove VGA font is the reference font, so museum and ansilove renderings share glyphs.
- pnpm's minimum release age policy is kept; the lockfile is resolved within it.
- Speculative dependencies removed from empty packages (YAGNI): they come with the code.
- Decisions are recorded as ADRs (`docs/adr/`, 0001–0008); explorations are time-boxed spikes
  whose code is never merged (`docs/spikes/`).
- Autonomous mode (ADR 0008): Claude merges its own pull requests on green CI.

## Problems met

- int10h.org (VileR font pack) is behind a captcha: font taken from libansilove instead.
- GitHub API rate-limited: tags read with `git ls-remote`.
- `pkill -f` with a pattern also present in its own command line killed the shell: kill by PID.
- Ruff formats Python blocks inside Markdown: `docs/` is excluded from ruff.
- SvelteKit 3 moved environment variables to `src/env.ts` and `$app/env/public`.
- Hooks must not mutate the environment: `uv run --no-sync` in pre-commit.
- First CI run: Paraglide output is generated, so a fresh clone lacked it (knip failed), and its
  generated files tripped Prettier. Fixed with `prepare` and `.prettierignore`.
