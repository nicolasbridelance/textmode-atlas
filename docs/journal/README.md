# Session journal

One file per working session, `YYYY-MM-DD.md` (add `-2`, `-3` for more sessions the same day),
written at the end of the session. It is the memory between sessions: the next one starts by
reading the latest entry and [the roadmap](../roadmap.md).

Sections, kept short:

- **Goal**: what the session set out to do.
- **Done**: what changed, with commits.
- **Decisions**: what was decided and why (and where it is recorded: spec, CLAUDE.md, code).
- **Problems met**: what went wrong, and what was learned.
- **State at the end**: what works, what does not, what is uncommitted.
- **Next**: the first thing to do next session.
