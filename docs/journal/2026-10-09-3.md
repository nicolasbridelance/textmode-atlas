# 2026-10-09 — visitor presentation workshop

## Goal

Start configurable framing/backgrounds, a light viewer theme, scripted reinterpretations and
an entrance shared by the daily work, thumbnails and constellations, at the owner's request.

## Done

- Dark/light/system museum themes, persistent local presentation settings, custom gallery
  background, thin frame and paper mount; EN/FR controls and preserved work query across locales.
- Pure pixel rules for white paper, glyph coverage greys, dots, diagonal touches and posterized
  graffiti; nearest-neighbour, browser interpolation and fixed-kernel Gaussian smoothing.
- Full-work PNG with companion JSON recipe, hashes, version, interpretation label, dimensions
  and browser context; bounded export size. Source records and grids remain untouched.
- `/explore` reads existing public lists, with whole-work thumbnails and radial metadata
  constellations; links return to the shared work screen. No private research dataset published.
- Documentation in `docs/presentation-workshop.md`; the foundation's default black room now
  explicitly permits these owner-requested choices.

## Decisions and limits

These are geometric experiments, not validated imitations of painting techniques. Density drops
colour intentionally. Smooth enlargement is browser-dependent, not LCD subpixel rendering.
Nearest-style edges remain pending authorized export. Frontend rules still target TMG1/VGA while
Claude implements grid v2 in the same shared checkout; backend files and services were untouched.
The initial browser visual review used project-made synthetic geometry; the report of an
unavailable public bucket was later corrected (see the follow-up below).

## Follow-up: public storage is healthy

The owner asked to restore the connection after the initial availability report. Diagnosis:
`localhost:3902` was the wrong endpoint inside the dev container; Garage runs in the sibling
`storage` container, and `TM_PUBLIC_FILES_ORIGIN=http://storage:3902` was already correct.
The direct public list and `/files` proxy both returned HTTP 200. No Garage restart or bucket
change was needed. The prior availability conclusion was incorrect.

A separate stale-preview issue prevented browser hydration: the long-running Vite process on
4174 referenced client chunks removed by subsequent builds. Restarted only that museum preview.
Verified the existing 366-entry public list, a real 640×800 work (`EL-TMP2.ANS`), its TMG1 grid,
conservation PNG, the paper interpretation and gallery thumbnails with no browser errors.
Screenshots are local ignored outputs in `apps/museum/test-results/storage-check/`.
